# ภาพจริง — สิ่งที่ต้องถ่าย ส่งยังไง และรันอะไร

หน้าเว็บมีช่องภาพ **24 ช่อง** (บวกช่องเสริมอีก 1) ตอนนี้ทุกช่องยังเป็นภาพชั่วคราวที่เขียนบอกไว้ว่า
ต้องใส่ภาพอะไร เมื่อมีภาพจริงแล้วขั้นตอนคือ **วางไฟล์ → รันคำสั่งเดียว** ที่เหลือสคริปต์จัดการให้หมด
ทั้งการครอบตัด ย่อขนาด แปลงเป็น AVIF/WebP/JPG และแก้ `index.html`

---

## 1. ส่งไฟล์มายังไง

เลือกทางไหนก็ได้ ขอเป็น **ไฟล์ต้นฉบับความละเอียดเต็ม** อย่าส่งภาพที่ผ่านการบีบจาก
LINE หรือแคปหน้าจอจาก TikTok — ภาพพวกนั้นถูกบีบมาแล้วรอบหนึ่ง พอเว็บบีบซ้ำจะเห็นรอยชัด
และภาพจาก TikTok มักติดลายน้ำกับชื่อบัญชี

| วิธี | เหมาะกับ |
|---|---|
| อัปโหลดไฟล์เข้าแชตนี้ | ส่งทีละไม่กี่รูป เร็วที่สุด |
| Google Drive (เชื่อมต่อไว้แล้ว) | ส่งทีเดียวหลายสิบรูป — สร้างโฟลเดอร์ `511salon-photos` แล้วบอกชื่อโฟลเดอร์มา |
| commit เข้า repo เอง | วางไว้ที่ `511salon/assets/img/_originals/` แล้ว push |

**ตั้งชื่อไฟล์ตามชื่อช่องในตารางข้อ 3** เช่น `hero.jpg`, `work-01.jpg`, `cmp-1-before.jpg`
ถ้าตั้งชื่อไม่ตรงก็ส่งมาได้ บอกมาว่ารูปไหนคือช่องไหน เดี๋ยวผมเปลี่ยนชื่อให้

## 2. ส่งชุดไหนก่อนดี

ไม่ต้องรอให้ครบ 24 รูป ส่งเป็นชุดได้ เว็บจะค่อย ๆ กลายเป็นของจริงทีละส่วน

**ชุดที่ 1 — 5 รูป เห็นผลมากที่สุด**
`hero` · `hero-portrait` · `work-01` · `work-02` · `work-03`

**ชุดที่ 2 — การ์ดผลงานเด่น 6 รูป**
`rail-keratin` · `rail-treatment` · `rail-volume` · `rail-perm` · `rail-color` · `rail-bleach`

**ชุดที่ 3 — เทียบก่อน–หลัง 6 รูป (3 คู่)**
ต้องครบทั้ง 6 รูปพร้อมกัน ไม่งั้นสคริปต์จะยังไม่แก้ส่วนนี้ให้ เพราะถ้าแปลงแค่บางคู่
พอผู้ชมกดสลับเคสจะเจอภาพเสีย

**ชุดที่ 4 — ที่เหลือ**
`work-04` ถึง `work-09` · `branch-keha` · `og`

## 3. ตารางช่องภาพทั้งหมด

| ชื่อไฟล์ | ใช้ที่ไหน | แนว | ถ่ายอะไร |
|---|---|---|---|
| `hero` | ภาพเต็มจอบนสุด (เดสก์ท็อป) | **นอน** | ลูกค้าหลังยืดเคราติน ถ่ายห่างพอให้เห็นทรงผมทั้งหัว เว้นที่ว่างฝั่งซ้ายไว้วางตัวอักษร |
| `hero-portrait` | ภาพเต็มจอบนสุด (มือถือ) | **ตั้ง** | คนเดียวกัน ท่าเดียวกัน แต่ถ่ายแนวตั้ง — ถ้าไม่มี เว็บจะเอา `hero` มาครอบซึ่งจะถูกตัดข้างจนเสียทรง |
| `rail-keratin` | การ์ดผลงานเด่น | ตั้ง | ยืดเคราติน — ผมฟอกประบ่า |
| `rail-treatment` | การ์ดผลงานเด่น | ตั้ง | เคราตินสด — ผมขาดจากการฟอก |
| `rail-volume` | การ์ดผลงานเด่น | ตั้ง | ยืดวอลลุ่ม — ตรงแต่โคนยังพอง |
| `rail-perm` | การ์ดผลงานเด่น | ตั้ง | ดัดดิจิตอล — ลอนกลางถึงปลาย |
| `rail-color` | การ์ดผลงานเด่น | ตั้ง | ทำสีผม — โทนน้ำตาลประกายหม่น |
| `rail-bleach` | การ์ดผลงานเด่น | ตั้ง | ฟอกสี + เชื่อมแกนผม — ปลายไม่ขาดยุ่ย |
| `cmp-1-before` / `cmp-1-after` | สไลเดอร์ลากเทียบ เคส 1 | ตั้ง | ผมฟอกแห้งชี้ฟู → ยืดเคราติน + เคราตินสด |
| `cmp-2-before` / `cmp-2-after` | สไลเดอร์ลากเทียบ เคส 2 | ตั้ง | ผมดัดเก่าปลายแตก → ยืดวอลลุ่ม |
| `cmp-3-before` / `cmp-3-after` | สไลเดอร์ลากเทียบ เคส 3 | ตั้ง | สีตกเป็นส้ม → ฟอกสี + เชื่อมแกนผม |
| `work-01` … `work-09` | แกลเลอรี 9 ช่อง | ตั้ง | ผลงานหลากหลายบริการ ดูคำบรรยายของแต่ละช่องได้ใน `index.html` |
| `branch-keha` | ส่วนที่ตั้งร้าน | นอน | หน้าร้าน ให้เห็นป้ายร้านและทางเข้าชัด ถ่ายกลางวัน |
| `og` | ภาพตอนแชร์ลิงก์ใน LINE/Facebook | นอน | ผลงานเด่นที่สุดหนึ่งภาพ ตัวแบบอยู่กลางภาพ ขอบจะถูกตัด |

ถ้าคำบรรยายในเว็บไม่ตรงกับภาพที่ส่งมา บอกได้ ผมแก้คำบรรยายตามภาพจริง —
คำบรรยายควรตามภาพ ไม่ใช่ให้ภาพตามคำบรรยาย

## 4. ถ่ายยังไงให้ใช้ได้

- **แนวตั้งเป็นหลัก** ช่องส่วนใหญ่เป็นแนวตั้ง ถ้าถ่ายแนวนอนมา จะถูกตัดข้างเยอะ
- **แสงเดียวกันทั้งชุด** ถ่ายจุดเดิมของร้านทุกครั้ง อย่าสลับระหว่างไฟในร้านกับแสงหน้าร้าน
  สีผมจะเพี้ยนจนดูเหมือนคนละงาน
- **ก่อน–หลัง ต้องเป็นคู่จริง** ระยะเท่ากัน มุมเท่ากัน แสงเท่ากัน พื้นหลังเดียวกัน
  ถ้าภาพ "หลัง" ถ่ายใกล้กว่าหรือสว่างกว่า คนดูจะรู้สึกว่าโดนหลอกทันที
- **ห้ามใช้ฟิลเตอร์ปรับสีผม** เชิงอรรถท้ายเว็บประกาศไว้แล้วว่าไม่ผ่านฟิลเตอร์เปลี่ยนสีผม
  ถ้าใช้จะกลายเป็นข้อความเท็จบนหน้าเว็บ
- **เว้นที่ว่างรอบตัวแบบ** ทุกช่องมีสัดส่วนตายตัวและจะถูกครอบตัด อย่าถ่ายชิดจนหัวติดขอบ
- **ความละเอียด** อย่างน้อย 1600px ด้านสั้น ถ่ายจากมือถือรุ่นไหนก็พอ ขอไฟล์ต้นฉบับ

**ความยินยอม** ภาพลูกค้าทุกภาพต้องได้รับอนุญาตให้เผยแพร่ก่อน เชิงอรรถข้อ 3 ท้ายเว็บ
ประกาศเรื่องนี้ไว้แล้ว ถ้ายังไม่ได้ขอ ต้องขอก่อนหรือไม่ก็แก้ข้อความนั้น

## 5. รันอะไร

```bash
pip install pillow pillow-heif           # ครั้งแรกครั้งเดียว (heif = อ่าน .heic ได้)
cd 511salon

python3 tools/process-photos.py --list         # ช่องไหนมีภาพจริงแล้ว ช่องไหนยังขาด
python3 tools/process-photos.py                # ทำทุกช่องที่มีไฟล์ตั้งชื่อตรงกับช่อง
python3 tools/process-photos.py hero work-01   # เฉพาะบางช่อง
python3 tools/process-photos.py --dry-run      # ดูก่อนว่าจะทำอะไร ยังไม่แตะไฟล์
```

**ทำงานบนเครื่องตัวเอง** ไม่ต้องก็อปไฟล์เข้ามาก่อน ชี้ไปที่โฟลเดอร์ภาพได้ตรง ๆ
และจับไฟล์ชื่ออะไรก็ได้เข้าช่องเองด้วย `<ช่อง>=<ชื่อไฟล์>`

```bash
python3 tools/process-photos.py --from ~/MyProjects/hair-photo --list
python3 tools/process-photos.py --from ~/MyProjects/hair-photo \
    hero=IMG_1234.jpg hero-portrait=IMG_1235.jpg work-05=IMG_1240.jpg
```

สคริปต์จะ

1. ครอบตัดตามสัดส่วนของแต่ละช่อง จากกึ่งกลางแนวนอน และ 38% จากขอบบนในแนวตั้ง
   (ใบหน้าคนมักอยู่ค่อนไปทางบน)
2. ย่อเป็น 3 ความกว้าง 480 / 960 / 1600 แล้วบันทึกเป็น AVIF + WebP + JPG
   ไม่ขยายภาพให้ใหญ่กว่าต้นฉบับ
3. แก้ `index.html` เปลี่ยน `<img>` ที่ยังชี้ภาพชั่วคราวเป็น `<picture>` พร้อม `srcset`
   โดยคง `alt` / `width` / `height` / `loading` เดิมไว้ครบ
4. ตั้ง `<link rel="preload">` ของ hero ให้ตรงกับไฟล์ที่เบราว์เซอร์จะเลือกจริงในแต่ละขนาดจอ
5. เปลี่ยน `og:image` เป็นไฟล์จริง เมื่อมีช่อง `og`

**ครอบตัดไม่สวย?** สร้าง `assets/img/_originals/focus.json` ระบุจุดโฟกัสเป็นเปอร์เซ็นต์
แล้วรันช่องนั้นซ้ำ

```json
{ "hero": [50, 25], "work-03": [40, 55] }
```

**หลังรันเสร็จ** เปิดดูด้วย `python3 -m http.server 8765` แล้วไล่ดูทุกส่วน
ถ้าพอใจแล้วค่อยลบ `assets/img/placeholder/` กับ `assets/img/_originals/` ทิ้ง
(`_originals` ไม่ต้อง commit — อยู่ใน `.gitignore` แล้ว)
